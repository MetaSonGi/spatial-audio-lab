# 🎧 공간 음향 랩 (spatial-audio-lab)

SuperCollider처럼 공간 음향을 직접 만들어 듣는 웹앱. WebAudio API의 HRTF 패닝으로 3D 입체 음향을 구현한다. 100% 브라우저에서 동작하며 외부 서버가 없다.

> 🎧 **이어폰·헤드폰 착용을 권장합니다.** 스피커로는 좌우·앞뒤 입체감을 느끼기 어렵습니다.

## 사용법

1. **🔊 오디오 시작** 버튼을 누른다 (브라우저 자동재생 정책 때문)
2. **🗺 공간 필드**에서 점을 드래그해서 음원을 이동한다
   - 🔵 파란 점 = 리스너(나). 드래그로 이동, 방향 슬라이더로 고개를 돌린다
   - 컬러 점 = 음원. 가까울수록 크게, 멀수록 작게, 방향에 따라 좌우·앞뒤로 들린다
3. **✨ 프리셋**으로 바로 시작하거나, **🔈 음원**을 직접 추가·설정한다
4. **🎚 마스터**에서 스펙트럼을 확인하고, **⏺ 녹음**으로 WebM 오디오를 저장한다

## 음원 설정 (최대 8개)

- **소리 종류**: 사인 / 사각 / 톱니 / 삼각 / 노이즈 (노이즈는 밴드패스 필터, 주파수 슬라이더가 필터 주파수)
- **주파수**: 40~2000Hz (로그 스케일)
- **볼륨**: 개별 음량
- **움직임**: 고정 / 공전(반경·속도 조절, 리스너 주위를 돈다) / 흔들림(LFO 진폭 조절)
- **개별 재생/정지**, 삭제

## 기술

- 각 음원에 `PannerNode` — `panningModel='HRTF'`, `distanceModel='inverse'`, `refDistance=1`, `maxDistance=50`, `rolloffFactor=1`
- 리스너는 Listener API로 위치·방향 반영 (음원 위치는 리스너 기준 상대좌표로 변환)
- 리버브: `ConvolverNode` + 코드로 생성한 2초 노이즈 디케이 임펄스 응답, wet/dry 조절
- 공전 애니메이션은 `requestAnimationFrame`에서 `panner.positionX.value` 등을 직접 업데이트
- 마스터 체인: `masterGain → AnalyserNode(스펙트럼) → destination`, 녹음용 `MediaStreamDestination` 병렬 연결
- 좌표계: 미터 단위, 리스너 중심, 캔버스 픽셀↔미터 매핑 (±12m 필드)

## 프리셋 4종

- 🌌 우주 드론: 디튠된 톱니파 3개가 천천히 공전
- 🌧 빗소리: 필터드 노이즈 4개가 사방에서
- 🐝 벌떼: 빠른 작은 공전 3개
- 🧘 명상: 느린 사인파 2개 + 리버브 강하게

## 제약·주의사항

- HRTF는 일부 모바일 Safari에서 `equalpower`로 폴백될 수 있다 (HRTF 우선 시도)
- `ctx.letterSpacing`이 아니라 WebAudio 기반이므로 관련 없음 — 참고로 구형 브라우저의 Listener API는 `setOrientation` 방식으로 폴백 처리됨
- 녹음 포맷은 브라우저에 따라 WebM(또는 MP4)으로 달라진다
- 외부 의존성 0 (CDN 없음, 시스템 폰트만 사용)
